GitHub Pages 무료 배포 가이드

이 슬롯 머신 게임은 단 하나의 index.html 파일로 구성되어 있어 GitHub Pages를 통해 무료로 웹 사이트로 무료 개설이 가능합니다!

  1. GitHub 저장소(Repository) 생성:
    GitHub에 로그인 후 github.com/new 이동 ➔ 저장소 이름(예: my-777-slot) 입력 후 Public 선택하여 생성합니다.
  2. index.html 업로드:
    이 코드 전체를 index.html 이름의 파일로 저장한 후 생성된 저장소에 Upload files 하거나 Git push합니다.
  3. Pages 기능 활성화:
    • 저장소 상단 메뉴의 Settings 탭을 클릭합니다.
    • 좌측 메뉴에서 Pages 메뉴를 클릭합니다.
    • Build and deployment > Branch에서 main (또는 master) 및 /(root) 선택 후 Save를 누릅니다.
  4. 완료 및 브라우저 접속:
    약 1~2분 후 주소창에 내 슬롯 머신 URL이 제공됩니다:
    https://<내-깃허브-아이디>.github.io/my-777-slot/
